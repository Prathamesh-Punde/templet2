# Perfect Software Solutions Website

A professional website for Perfect Software Solutions showcasing their software products and services.

## 📁 Project Structure

```
templet2/
│
├── index.html              # Home page with hero section and featured products
├── about.html              # About us page with company information
├── product.html            # All products listing page
├── support.html            # Customer support and FAQ page
├── careers.html            # Career opportunities and job listings
├── contact.html            # Contact form and location information
│
├── styles.css              # Main stylesheet (responsive design included)
├── script.js               # JavaScript functionality
├── logo.jpeg               # Company logo

├── assets/                 # Asset files
│   └── pdfs/              # PDF documents
│       ├── Excise Managment.pdf

│
```

## 🔧 Customization

### Colors:
Edit CSS variables in `styles.css`:
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    --accent-color: #ec4899;
    /* ... more variables */
}
```

### Content:
- Update company information in HTML files
- Replace `logo.jpeg` with your logo
- Update contact information in footer and contact page
- Modify PDF paths in product cards
